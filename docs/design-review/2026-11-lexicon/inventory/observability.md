## Top 3 by payoff against cost

1. **Return the correlation ID on every response, including web.** Add `X-Correlation-ID` to CORS allowed and exposed headers (`router.go:41,49`), drop the web skip (`correlationId.ts:8`), and put `correlation_id` in `ErrorResponse` (`errors.go:16-19`).
   It takes a few lines. Every web failure then becomes traceable to a log line, and the client uses one key spelling.
2. **One request-outcome middleware and one field vocabulary.** Merge the duration and status measurement from telemetry, reqmetrics and RequestLogger into one middleware. It emits route template, corr_id, trace_id and user_id once, through exported key constants in `shared/logging`, and the duplicate discovery error logs go.
   This is small to medium work. It gives one home for logs, metrics and traces, trace-to-log links, and fewer ERROR lines per failure.
3. **One metrics registry injected from `app`.** Replace the per-feature expvar globals (auth, catalog, playback, discovery, app) with a shared registry passed through each feature's metrics port, and add the missing denominators (play attempts) plus a 5xx-ratio symptom alert read from it.
   This is medium work. It ends hand-assembled snapshots and globals, and gives the SLO and alert work one source.
