## Top 3 by payoff against cost

1. **Put the user into the auth middleware's contract, and log who did each write in one place.** Delete the 38 RequireUserID branches, discovery's `requireUser` and the third 401 shape; the auth middleware writes `user_id` into a holder the request logger reads.
   Mechanical change across about 15 handler files. It removes a cross-cutting concern done by hand and fixes the scattered audit trail in the same pass.
2. **Fix the CORS policy and turn correlation ids back on for web.** Drop AllowCredentials, allow `X-Correlation-ID` and `Last-Event-ID`, expose `Retry-After` and `X-Correlation-ID`, and delete the web skip in `correlationId.ts:8`.
   About 10 lines plus a preflight test. Prod web requests become traceable end to end, and it takes away a privilege the API never used.
3. **Separate the migration role from the app role (least privilege).** The app role gets DML only on its tables, and prod-migrate uses an owner role.
   Small SQL and deploy change. A leaked app credential or SQL injection can then no longer drop or alter the schema. It also gives the "one table, one writer" rule a lever: grant `UPDATE tracks` only to the role that owns it.
