## Top 3 by payoff against cost
1. **Typed event payloads in `shared/events`, with one TS contract.** About 17 Publish sites change in one move.
   It ends silent key drift between Go and the client, which already shows at `acquisitionEvents.ts:46`.
2. **One retry policy.** Delete the ytmusic retry loop, which stacks 2×3 attempts on egress. Add jitter to `retryBackoff`.
   It is a few lines and removes a reliability-rule breach on the hottest integration point.
3. **Null Object cleanup.** Required dependencies fail in the constructor. Optional ones get a no-op at wiring time.
   It removes about 20 scattered nil checks and the no-op that hides a missing scheduler (`add_track.go:60-64`).

Unverified: whether TrackLedger has a contract test, which a grep for one did not find. Whether the discovery `requireUser` (`discovery_handler.go:153`) and the roughly 38 `RequireUserID` checks only repeat what the auth middleware already guarantees.
