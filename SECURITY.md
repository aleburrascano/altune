# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub:
[**Report a vulnerability**](https://github.com/aleburrascano/altune/security/advisories/new).

Private vulnerability reporting is enabled on this repository, so the report
stays between you and the maintainer until a fix ships.

Expect a first response within a few days. Please include what you found, how to
reproduce it, and the impact you think it has.

## Supported versions

Altune ships from `main`; only the latest release is supported. Fixes land on
`main` and go out in the next release rather than as backports.
