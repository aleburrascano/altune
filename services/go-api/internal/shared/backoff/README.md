`backoff` owns how long to wait before the next attempt of anything that retries: exponential from a base, capped, with a jitter shape the caller names.

`Ceiling(attempt)` is the wait without jitter, for attempt 1, 2, 3 and so on. It grows by `Factor` per attempt (2 when unset) and stops at `Cap`; a `Cap` of zero means no cap, so a caller that wants a bound sets one. `Spread` is a fraction in [0, 1]. `DelayAt(attempt, unit)` places the wait by `unit` in [0, 1), so a test passes the point it wants: with `Spread` unset it is equal jitter, within [ceiling/2, ceiling]; with `Spread` set it is symmetric, within ceiling plus or minus `Spread` of the ceiling. `Delay(attempt)` draws `unit` at random. A caller whose tests pin exact waits uses `Ceiling` and sets no jitter.
