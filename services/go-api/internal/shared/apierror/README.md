Contracts: `apierror` owns the one catalog of error codes a feature hands back to a client.

A `CodedError` carries a code from the catalog in `codes.go`, and each code names its kind (not found, conflict, invalid…), never an HTTP status. Only the HTTP boundary in `shared/httpserver` turns a kind into a status. Two coded errors are the same error under `errors.Is` when they share a code, whatever their detail or retry wait, so a sentinel keeps matching its retryable copies; one code means one condition, so never give two sentinels the same code. Adding, renaming or removing a code is a change to the public API contract, so the catalog test lists every code.
