Infrastructure: `ids` owns the identifiers every module shares: entity, track and user ids.

A `Source` is the func that supplies the UUIDs behind new ids. `Real` is the production source, and the composition root hands it to code that mints ids; a `Source` builds a user, track or entity id, or a plain string, with `NewUserId`, `NewTrackId`, `NewEntityId` and `NewString`. Code that mints ids takes a `Source` instead of calling `uuid.New`, so a test can hand it `idstest.Sequence()` and know every id. Parsing an id from text needs no source. A constructor that takes a `Source` refuses nil with an error that names it. Contract helpers that run against a shared database keep `ids.Real`, because a fresh counter could collide with rows an earlier run left.
