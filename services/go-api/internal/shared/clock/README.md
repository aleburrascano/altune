`clock` owns how code reads the time. A decision that depends on the time takes a `clock.Func` from its composition root and calls it, instead of calling `time.Now` itself, so a test can say what time it is. `time.Now` satisfies `clock.Func`, and `Func.UTC()` reads it in UTC, the form every stored timestamp uses. A required clock is a constructor parameter with no default. A constructor refuses a nil clock with an error (`alerts.Conditions`, `NewEventTap`, `NewAlertMonitor`, the search-history, audio-link, backfill, stream, audio-URL, track-handler, playlist-handler and discovery constructors, `NewSupabaseJWTVerifier`, `httpserver.NewUserRateLimiter`, `breaker.New`, `auth.Middleware`, `NewPlaylistLifecycleService`, `NewPlaylistMembershipService`, `NewAddTrackService`, `NewQueueHandler`, `queue.New`, `NewNowPlayingReader` and `logging.NewRingBuffer`). The `MustNew*` helpers panic, and are for a clock that is non-nil when the code is written (`time.Now`, a test fake) or that the caller has already checked (the private limiter and breaker helpers). The housekeeping jobs take the clock positionally and do not check it.

A wait is a `clock.Sleeper`: `func(ctx, d) error` that returns nil after `d`, or the context's error as soon as it ends, and returns at once for a `d` of zero or less. `clock.Sleep` is the production one; code that waits takes a `Sleeper` as a required parameter and refuses a nil one with an error that names the constructor (`youtubemusicapi.NewBudget` is the first). Sites that still call `time.NewTimer` or `time.After` for such a wait move to a `Sleeper` as their owners touch them. Tests drive a clock with `clocktest.Manual` (`clock/clocktest`), not a hand-rolled fake. New and converted seams declare their clock as `clock.Func`; the remaining option-style seams (the yt-dlp inspection clock, `logging.SetupWithClock`) still take `func() time.Time` and are converted as their files come free.

Measuring how long something took (`time.Since`) stays with the standard library; only the question "what time is it" goes through the port.
