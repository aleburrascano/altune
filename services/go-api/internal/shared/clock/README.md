Infrastructure: `clock` owns how code reads the time.

A decision that depends on the time takes a `clock.Func` from its composition root and calls it, instead of calling `time.Now` itself, so a test can say what time it is. `clock.Now` is the production `clock.Func` (the composition roots pass it, never `time.Now`), and `Func.UTC()` reads it in UTC, the form every stored timestamp uses. A required clock is a constructor parameter with no default. A constructor refuses a nil clock with an error (`alerts.Conditions`, `NewEventTap`, `NewAlertMonitor`, the search-history, audio-link, backfill, stream, audio-URL, track-handler and playlist-handler constructors, `NewSupabaseJWTVerifier`, `httpserver.MustNewUserRateLimiter`, `breaker.MustNew`, `NewPlaylistLifecycleService`, `NewPlaylistMembershipService`, `NewAddTrackService`, `NewQueueHandler`, `NewNowPlayingReader`). A constructor with no error return, such as `NewLibraryTracks`, panics on a nil clock. The `MustNew*` helpers panic, and are for a clock that is non-nil when the code is written (`time.Now`, a test fake) or that the caller has already checked (the private limiter and breaker helpers). The housekeeping jobs take the clock positionally and do not check it.

A wait is a `clock.Sleeper`: `func(ctx, d) error` that returns nil after `d`, or the context's error as soon as it ends, and returns at once for a `d` of zero or less. `clock.Sleep` is the production one; code that waits takes a `Sleeper` as a required parameter and refuses a nil one with an error that names the constructor (`youtubemusicapi.NewBudget` is the first). Sites that still call `time.NewTimer` or `time.After` for such a wait move to a `Sleeper` as their owners touch them. Tests drive a clock with `clocktest.Manual` (`clock/clocktest`), not a hand-rolled fake. New and converted seams declare their clock as `clock.Func`; the remaining option-style seams (the yt-dlp inspection clock) still take `func() time.Time` and are converted as their files come free.

A repeating loop takes a `clock.TickerFunc`: `func(d) (ticks <-chan time.Time, stop func())`, a fixed-rate ticker whose schedule does not shift when a run is slow. `clock.NewTicker` is the production one. `background.Every` refuses a nil one with `ErrTickerRequired` naming `background.Every`; `jobs.Runner` carries it as `NewTicker`, beside its `Now`, both set once by `app.New`, and refuses to register a job without either. A constructor or middleware with no error return refuses a nil clock with a panic that names it (`health.Check`, `sourcecheck.Run`, `background.RunJob`, `httpserver.ObserveRequests`, `httpserver.WriteDeadline`, `NewEventStreamHandler`, `NewObserveHandler`, `NewClientEvents`); `leader.NewElection`, `retry.New`, `alert.NewMonitor`, the eval meter and `youtubemusicapi.NewBudget` return an error naming the constructor, and the loops they own (the election, the alert monitor, the eval meter, the SSE heartbeats) tick on the injected `TickerFunc`. `clocktest.Manual.Ticker()` ticks as `Advance` crosses each interval.

Measuring how long something took reads the same clock: take the `clock.Func` and write `now().Sub(start)`, not `time.Since` or `time.Until`, so a test can pin both ends. The `forbidigo` rule in `.golangci.strict.yml` fails any production read of the wall clock (`time.Now`, `Since`, `Until`, `After`, `AfterFunc`, `NewTimer`, `NewTicker`, `Tick`) outside this package and the `*test` packages.
