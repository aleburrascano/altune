`clock` owns how code reads the time. A decision that depends on the time takes a `clock.Func` from its composition root and calls it, instead of calling `time.Now` itself, so a test can say what time it is. `time.Now` satisfies `clock.Func`, and `Func.UTC()` reads it in UTC, the form every stored timestamp uses. A required clock is a constructor parameter with no default. A constructor refuses a nil clock with an error (`NewEventTap`, `NewAlertMonitor`, the search-history, audio-link, backfill, stream, audio-URL, track, playlist and discovery constructors, `NewSupabaseJWTVerifier`). A panic lives only in the `MustNew*` helpers, which the composition roots and tests call with a hard-coded `time.Now`. The housekeeping jobs take the clock positionally and do not check it.

Tests drive a clock with `clocktest.Manual` (`clock/clocktest`), not a hand-rolled fake. New and converted seams declare their clock as `clock.Func`; the remaining option-style seams (the yt-dlp inspection clock, `logging.WithClock`) still take `func() time.Time` and are converted as their files come free.

Measuring how long something took (`time.Since`) stays with the standard library; only the question "what time is it" goes through the port.
