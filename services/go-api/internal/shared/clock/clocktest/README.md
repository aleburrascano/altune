`clocktest.Manual` is the one fake clock for tests of code that takes a `clock.Func`. It starts at the time it is given, moves only when the test calls `Advance` or `Set`, and is safe to read and advance from many goroutines. Pass `m.Func()` (or `m.Now`) where the code under test wants a `clock.Func`.

`m.Sleeper()` is a `clock.Sleeper` on the same clock: a sleep wakes only when `Advance` or `Set` moves the clock to its deadline, or when its context ends, and `m.Sleeping()` counts the sleeps still waiting, so a test advances time without waiting on the wall clock. `m.BlockUntil(n)` blocks until at least `n` sleeps, timers or tickers are waiting, so a test that starts the code under test in a goroutine waits for it to register instead of spinning or sleeping; under `synctest` the wait is durable, so `synctest.Wait` still settles.

Production code never imports this package. A test that needs a clock which ticks on every read, or one that fails, writes that behaviour next to the test that needs it.
